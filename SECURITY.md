# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose user data,
execute untrusted code, or bypass platform security. Use GitHub's private
security advisory feature for this repository. Include affected versions,
reproduction steps, impact, and any proposed mitigation.

## Scope

Security reports should concern this project's original code, build scripts, or
runtime integration. Questions about acquiring game files, bypassing copy
protection, antivirus exclusions, or disabling operating-system security
features are outside the supported workflow.

The project is experimental and provides no warranty. Run locally built binaries
only when you trust their source and build environment.
